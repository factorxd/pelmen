🥟 Пельмень — руководство пользователя

Актуальная версия — в меню «Справка → О программе».

Пельмень — простой шаблонизатор документов. Вы создаёте в Word шаблон с тегами вида {{ имя_поля }}, а программа подставляет в него данные из формы и генерирует готовые документы.

📁 1. Папка с шаблонами

При первом запуске программа попросит указать папку с вашими шаблонами .docx. Все файлы из этой папки и вложенных подпапок появятся в левой панели в виде дерева.

  • Файл → Открыть папку с шаблонами или Ctrl+O — сменить папку.
  • 🔍 Поиск — фильтрует шаблоны по имени.
  • ✖ — очистить поиск.
  • ⭯ — обновить список шаблонов. Полезно, если вы отредактировали шаблон в Word или добавили новый файл, не закрывая Пельмень.

📝 2. Создание шаблона в Word

Вставьте в документ теги вида {{ имя_поля }}. Имена переменных — только латиница, цифры и подчёркивание, начинаться должны с буквы или подчёркивания. Кириллица в тегах не поддерживается.

Простые поля

Договор с {{ client_name }} от {{ date }}

Повторяющиеся блоки

{% for item in spisok %}
{{ item.nazvanie }}, {{ item.cena }}
{% endfor %}

Условные блоки

{% if flag %}
Этот текст появится, если flag = true
{% else %}
Этот текст — если false
{% endif %}

⚙️ 3. Настройка шаблона

Кликните на шаблон в левой панели — справа появится форма. Нажмите ⚙️ Настройки шаблона, чтобы настроить поля.

Вкладка «Свойства полей»

  • Отображаемое имя — русская подпись для поля. Двойной клик по ячейке — редактирование.
  • Тип поля — text, number, date, bool или image.
    • bool — в форме появится чекбокс (удобно для условий {% if %}).
    • image — путь к файлу картинки, она встраивается в документ.
  • Формат — для типов date и number (см. ниже).

Вкладка «Категории»

Поля и блоки можно группировать по вкладкам в форме. Например: «Клиент», «Реквизиты», «Итого».

  • Кнопки Добавить / Удалить / Переименовать управляют категориями.
  • Перетаскивайте поля из дерева справа на категорию в списке слева (стрелка ⇠ подсказывает направление).
  • Порядок категорий меняется перетаскиванием в левом списке.

Экспорт и импорт настроек

Внизу диалога — кнопки 📤 Экспорт и 📥 Импорт. Настройки одного шаблона сохраняются в .json, их можно перенести на другую машину.

📅 4. Форматирование дат

Для полей типа date доступны предустановки, а также Свой формат... в стиле Python strftime.

Что ввестиПример вывода
%d.%m.%Y31.12.2025
%d %B %Y31 декабря 2025
%d %b %Y31 дек 2025
%Y-%m-%d2025-12-31
%d.%m.%y31.12.25

Форматы с %B и %b выводят русские названия месяцев независимо от системной локали.

В поле выбора даты отображается та же маска, что задана в настройках поля. Календарь (стрелка справа) — стандартный.

🔢 5. Форматирование чисел

Для полей типа number доступны предустановки, а также Свой формат... в стиле Python f-строк.

Формат вводится как {:,.2f} руб. — две цифры после запятой, разделитель тысяч — запятая, суффикс — « руб.». Программа автоматически переводит результат в русскую нотацию: 1 234,56 руб.

ФорматПример для 1234.56
{}1234.56
{:,.0f}1 235
{:,.2f}1 234,56
{:,.2f} руб.1 234,56 руб.
{:,.2f} ₽1 234,56 ₽
Пока поле в фокусе — отображается сырое число, удобное для правки. Как только вы уходите из поля (Tab, клик мимо, Enter) — оно форматируется.

📄 6. Заполнение формы и генерация

После выбора шаблона справа появляются вкладки категорий. Заполните поля:

  • 📄 Скачать DOCX — сохранить готовый документ.
  • 🔄 Очистить форму — сбросить все поля и черновик.
  • Для повторяющихся блоков — кнопки + Добавить ещё и 🗑️ Удалить.

💾 7. Автосохранение черновиков

Все изменения в форме сохраняются автоматически (по умолчанию каждые 0.5 сек). При повторном открытии шаблона данные восстанавливаются. После нажатия Скачать DOCX черновик удаляется.

Интервал автосохранения можно изменить в настройках программы.

📊 8. Массовая генерация из CSV/Excel

  1. Выберите файл .csv, .xlsx, .xls или .xlsm.
  2. Сопоставьте колонки файла с полями шаблона. Совпадающие названия подставляются автоматически.
  3. Выберите режим:
    • Один файл (с разрывами страниц) — все документы объединяются в один, каждый начинается с новой страницы.
    • Несколько файлов — каждый документ сохраняется отдельно. Можно упаковать в ZIP или сохранить в папку.
  4. Для режима «Несколько файлов» можно задать маску имени: Счет_{doc_number}_{client_name} — в фигурных скобках подставляются значения полей.
  5. Нажмите Сгенерировать.

Программа учитывает типы полей (дата, число) и применяет заданные форматы к значениям из файла.

👁️ 9. Предпросмотр

Генерирует временный DOCX и открывает его в Microsoft Word (или в программе по умолчанию).

🧩 10. Помощник разметки

Три вкладки, в каждой — конструктор тега с предпросмотром. Готовый тег копируется в буфер обмена:

  • Простые поля — {{ var }}.
  • Повторяющиеся блоки — {% for item in list %}...{% endfor %}.
  • Условные блоки — конструктор с поддержкой операторов ==, !=, >, >=, <, <=, in, not in, неограниченным числом elif и опциональным else.

📋 11. Пресеты

Пресет — это заранее сохранённый текст (например, название организации, ИНН, адрес), который можно быстро вставить в поле.

  • Пресеты группируются по категориям.
  • Вставка: правый клик в поле → Вставить из пресетов → нужный пресет.
  • Двойной клик по значению пресета в таблице — копирует значение в буфер обмена.

⚙️ 13. Настройки программы

Файл → Настройки

  • Папка с шаблонами — путь к директории.
  • Тёмная тема — переключение оформления.
  • Проверять обновления при запуске — тихая проверка через 15 сек после старта. Если обновление найдено, уведомление появится при следующем запуске, чтобы не отвлекать от работы.
  • Размер шрифта — от 6 до 24 pt, применяется ко всему интерфейсу.
  • Интервал автосохранения — от 0.1 до 5 сек.
  • Проверить обновления сейчас — немедленная проверка с переходом на страницу загрузки.

🔒 14. Ложные срабатывания антивирусов

Пельмень — программа на Python, собранная через PyInstaller. EXE-файл не подписан цифровым сертификатом (это дорого для небольшого проекта). Из-за этого Windows Defender, SmartScreen и сторонние антивирусы иногда ругаются на файл — это ложное срабатывание.

Что можно сделать:
  • Проверить файл на VirusTotal — если угроз не найдено, у вас ложное срабатывание.
  • Добавить EXE в исключения антивируса.
  • Скачивать релизы только со страницы загрузки.
